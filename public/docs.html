B2B Order API

Une API volontairement compacte pour les integrations metier : commandes idempotentes, stock protege et reponses JSON previsibles, sans framework ni dependance cote navigateur.

Commandes

        

            
GET/ordersListe paginee des commandes recentes

            
Parametres : page (defaut 1), per_page (defaut 20, max 100). Les commandes les plus recentes apparaissent en premier.

            

                
                
                

                

            

        

        

            
GET/orders/{id}Detail d'une commande

            
Retourne le statut, le total, la date de creation et les lignes avec leur prix fige au moment de la commande.

            

                
                

                

            

        

        

            
POST/ordersCreer une commande

            

                Envoyer Content-Type: application/json et une cle stable dans Idempotency-Key.
                
{
  "customer_id": 42,
  "items": [
    { "product_id": 1, "quantity": 2 }
  ]
}

            

            

                
                

                    
                    
                

                

                
                

                

            

        

        
Une cle et un contenu identiques renvoient le meme identifiant sans decrementer le stock une seconde fois. Reutiliser une cle avec un autre client ou panier retourne 409 idempotency_conflict. Le stock est verifie et reserve dans la meme transaction.

    Erreurs et exploitation
    
        
    Les erreurs suivent le format {"error":"code","message":"..."}. Codes principaux : 400 JSON invalide, 404 produit absent, 409 stock ou idempotence, 415 type de contenu, 422 validation, 503 base indisponible. Chaque reponse inclut X-Response-Time-ms.
    
    
    
    
    OpenAPI ecrit a la main, servi directement par l'API. Aucun Swagger UI distant ni ressource tierce.
