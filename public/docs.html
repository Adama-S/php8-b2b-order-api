POST/ordersCreate an order

            

                Send Content-Type: application/json and a stable key in Idempotency-Key.
                
{
  "customer_id": 42,
  "items": [
    { "product_id": 1, "quantity": 2 }
  ]
}

            

            

                
                

                    
                    
                

                

                
                

                

            

        

        
The same key and order content return the same order without decrementing stock again. Reusing a key with a different customer or cart returns 409 idempotency_conflict. Stock is checked and reserved in the same transaction.

    Errors and operations
    
        
    Errors use the format {"error":"code","message":"..."}. Main status codes: 400 invalid JSON, 404 product not found, 409 stock or idempotency conflict, 415 unsupported content type, 422 validation error, 503 database unavailable. Each response includes X-Response-Time-ms.
    
    
    
    
    Handwritten OpenAPI, served directly by the API. No remote Swagger UI or third-party resources.
